# SEO Content Template for Tool Pages

**IMPORTANT**: This template is now deprecated. Use the new strategic SEO workflow outlined in PROJECT_RULES.md Section 7.

## New Strategic Approach: Two-Phase SEO Workflow

### Phase 1: Keyword Research & Strategy
Before writing content, define your keyword hierarchy:

**mainKeyword**: Single most important phrase (targets #1 ranking)
**secondaryKeywords**: Array of long-tail keywords (become H2 headings)
**relatedKeywords**: LSI keywords for topical authority

### Phase 2: Content Generation
Use the "Official Generate SEO Content Prompt Template" from PROJECT_RULES.md with these inputs:
- Tool Name
- Main Keyword
- Secondary Keywords Array
- Related Keywords Array

## Strategic Content Structure (800-1200 words):

### 1. Understanding the [Tool Name] (H2)
- **Purpose**: Introduction using mainKeyword in first paragraph
- **Word Count**: 150-200 words
- **SEO Focus**: Natural mainKeyword integration, tool benefits

### 2. How to Use Our [Main Keyword] (H2)
- **Purpose**: Step-by-step user guide
- **Word Count**: 150-250 words
- **SEO Focus**: Practical value, user-focused instructions

### 3. Deep Dive Sections (H2s for Each Secondary Keyword)
- **Purpose**: One H2 section per secondaryKeyword
- **Word Count**: 200-300 words each
- **SEO Focus**: Each secondaryKeyword as primary section focus
- **Example**: "Demystifying the Flesch-Kincaid Score" (for secondary keyword "flesch kincaid score")

### 4. Frequently Asked Questions (H2)
- **Purpose**: Address user concerns, include mainKeyword in one question
- **Word Count**: 200-300 words
- **SEO Focus**: Natural mainKeyword usage, comprehensive answers

### 5. [Tool Name] and Your Workflow (H2)
- **Purpose**: Conclusion + related tool suggestions
- **Word Count**: 100-150 words
- **SEO Focus**: Final mainKeyword mention, internal linking

## Critical SEO Rules:
- **Main Keyword Density**: 0.8% (appears in intro, FAQ, conclusion)
- **Secondary Keywords**: Each gets dedicated H2 section
- **Related Keywords**: Naturally distributed throughout
- **Readability**: Short sentences, bold highlights, bullet points
- **Value Rule**: Every sentence must provide user value
- **No Fluff Policy**: Direct, helpful content only

## Content Quality Standards:
- **Tone**: Clear, helpful, slightly informal
- **Structure**: Semantic HTML with proper heading hierarchy
- **Formatting**: Use `<strong>`, `<ul>`, proper paragraph breaks
- **Internal Links**: Reference related tools and categories
- **User Focus**: Write for users first, search engines second

## Implementation Process:
1. **Research**: Define mainKeyword, secondaryKeywords, relatedKeywords
2. **Generate**: Use the official SEO prompt from PROJECT_RULES.md
3. **Review**: Ensure keyword density and structure compliance
4. **Integrate**: Add HTML content below tool interface
5. **Validate**: Check word count (800-1200), heading structure, keyword usage

This strategic approach ensures every tool page has world-class SEO content designed to rank #1 for competitive keywords.
